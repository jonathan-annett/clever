Inputs

Plays the reference input (a CD player, a laptop, a desk send) straight to the Output device above, so the amp can be fed without a desk. It replaces the generator. If the reference and mic share an interface, only the reference channel is passed. Never pass through a live mic.

Input changes restart the engine. Browser echo cancellation, noise suppression and auto gain are switched off.

Generator

Level is RMS in dBFS. The generator also feeds the reference channel when Reference is set to the internal loopback.

Voice
Rules

Checks a vocal against the shape of natural speech and suggests cuts for the channel strip: a high-pass for pops and rumble, low-mid cuts for proximity, notches for resonances, and gentle cuts for nasal, harsh or sibilant tones. It only listens while someone is speaking above the gate. Suggestions are cuts only, and it warns when they would cost enough speech level that you'd need more gain.

Listen

Headphones only. If the mic can hear this output it will feed back. Mic − reference subtracts the reference after the measured delay and gain; Mic − predicted subtracts the reference passed through the measured impulse response, leaving what the reference can't explain: room noise, distortion, the late reverb tail and anything that changes. Find delay first, and keep both inputs on one interface. Pick a different output from the one feeding the PA.

Transfer function
Levels

Set the reference once the feed is at a good level, then watch the drift readout. You can also click or drag on the graph to place it. LUFS uses BS.1770 K-weighting on one channel; Leq uses the SPL meter's weighting and, for the mic, its calibration. Choose the reference input to watch a desk or stream feed directly; both inputs are recorded all the time, and each keeps its own reference.

Bands

Match the layout to your graphic EQ so each column is one fader. Custom takes the centre frequencies from your graphic's faceplate; "2k5" and "2.5k" both work. Floor and ceiling are in dBFS. Ignored bands are remembered by frequency.

Below the silence gate (overall level in dBFS) nothing counts as hot, so the readout doesn't point at the noise floor. Press Set from noise while the room is quiet to put the gate 6 dB above it.

RTA & Spectrograph

Spectrograph floor and ceiling are in dBFS.

SPL meter

SPL from the UMIK-1 sensitivity factor is close but not certified. For accuracy, fit a 94 or 114 dB calibrator and press the button above.
